## E-Commerce Price Comparison Website (WiseBuyer)

### Technologies Used

Python, Flask, Pandas, BeautifulSoup, HTML, CSS, Bootstrap

### Project Description

Developed a web-based price comparison platform that enables users to compare product prices across multiple e-commerce websites through a single interface.

### Key Features

* Implemented web scraping using Python and BeautifulSoup to collect product information and pricing data from multiple online shopping platforms.
* Built a responsive and user-friendly interface using HTML, CSS, and Bootstrap for seamless product search and comparison.
* Developed the backend using Flask to handle user requests, process product data, and display comparison results efficiently.
* Integrated CSV-based data storage and filtering mechanisms for faster product search and retrieval.
* Designed a comparison dashboard that displays product names, prices, and platform-specific information in a structured format.
* Implemented keyword-based search functionality to help users quickly find and compare products.
* Improved user experience with dynamic result rendering and responsive design principles.

### Outcome

The platform simplifies online shopping by allowing users to compare prices across different e-commerce websites, helping them make cost-effective purchasing decisions.
